# Delicious Indian Restaurant

## Project Overview
Delicious Indian Restaurant is a restaurant website designed to showcase Indian cuisine through an attractive, user-friendly, and responsive interface. It provides visitors with an easy way to explore food offerings and restaurant information.

## Features
- Responsive website design
- Food and menu presentation
- Clean and intuitive navigation
- Attractive user interface
- Mobile-friendly layout

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Objective
Developed to enhance frontend development skills and gain practical experience in responsive web design, website layout, and interactive user interfaces.

## Live Demo
"https://bhagya147.github.io/Indian-delicious/

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
